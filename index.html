LinkedIn Publishing API
ℹ
Setup steps:
1. Go to linkedin.com/developers → Create App
2. Request the Share on LinkedIn product
3. Get your OAuth 2.0 Access Token
4. Find your Person URN: urn:li:person:XXXXXXXX
Facebook Publishing API
ℹ
Setup steps:
1. Go to developers.facebook.com → My Apps → Create App
2. Add Pages API product
3. Generate a Page Access Token (not user token)
4. Find your Page ID from your Facebook Page settings
